Bulong vs Apple Dictation for Filipino and Taglish.

Apple Dictation is free, already installed, and good enough for many people. Bulong is a focused alternative for people who want visible offline behavior, Taglish testing, push-to-talk, and a local transcript history.

Where Apple Dictation is the better choice

Start with Apple Dictation if you dictate occasionally, do not want to install anything, or mainly use a language and vocabulary it already handles well. It is built into macOS and costs nothing.

Apple also lets you choose a Dictation shortcut, enable automatic punctuation in supported languages, switch between configured languages, and continue typing while dictating on Apple Silicon. Its capabilities can vary by language, region, Mac model, and macOS release.

Source: Apple’s current “Dictate messages and documents on Mac” guide.

Where Bulong is different

Taglish is a primary use case

Bulong is built by a Filipino developer who code-switches during everyday work. The homepage publishes raw Filipino-English examples—including a real recognition mistake—so you can judge the result rather than relying on a language-support checkbox.

Offline behavior is simple to verify

Bulong downloads a local speech model, then transcribes without a network connection. It does not include analytics, crash reporting, cloud history, or an online license check.

Hold-to-talk and toggle are both available

A custom shortcut can behave like push-to-talk—hold it while speaking and release to finish—or like a toggle. Apple Dictation offers a configurable start-and-stop shortcut, but not the same hold-to-talk workflow.

Transcript history is part of the app

Bulong keeps a searchable local history and can export it. Apple Dictation inserts text into the active field but does not provide a separate transcript-history window.

Privacy requires checking your settings

Apple explains that you can check Keyboard settings to see whether general Dictation for your selected language needs an internet connection and whether voice input is processed on-device. Apple also provides controls for sharing audio recordings used to improve Siri and Dictation.

Bulong takes a narrower approach: the transcription models run locally, and the only app network activity is downloading those models. Both choices can be reasonable; the difference is how much configuration and trust each workflow requires.

Which should you use?

  • Choose Apple Dictation if free, built-in access is your priority and it already recognizes your normal speech well.
  • Try Bulong if you regularly speak in Taglish, want hold-to-talk, need searchable local history, or want transcription that is designed to keep working after Wi-Fi is turned off.

The fairest test is to dictate the same five sentences into both tools, using the same microphone and environment, then compare the unedited results and correction time.

For a repeatable test, use the examples in the Taglish dictation guide.
